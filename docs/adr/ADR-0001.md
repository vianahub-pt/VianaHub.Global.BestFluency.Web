# ADR-0001 — Arquitetura inicial da landing: static-first, multilíngue e sem acoplamento de fornecedor

- **Status:** Aceito
- **Data:** 2026-08-05
- **Issue:** [#3 — Auditoria e arquitetura inicial da landing](https://github.com/vianahub-pt/VianaHub.Global.BestFluency.Web/issues/3)
- **Decisores:** PO, Kanban Coordinator, Developer Senior, UI/UX
- **Revisores:** QA (landing page)

## Contexto

A landing da Best Fluency Language School precisa ser publicada com custo baixo,
performance alta, SEO internacional forte e independência de fornecedor de
hosting. A spec V2 (`docs/landing-page-spec-v2.md`) e a auditoria
(`docs/analise-site-best-fluency.md`) exigem:

- 7 idiomas publicados (`pt-PT`, `en-US`, `es-ES`, `fr-FR`, `de-DE`, `it-IT`,
  `pt-BR`), cada um com URL própria;
- SEO internacional completo (canonical autorreferencial, `hreflang`
  recíproco, `x-default`, sitemap, robots);
- temas light/dark sem flash e com contraste AA;
- mobile-first (360/375/390/412 px antes de desktop);
- contacto direto por WhatsApp contextual por secção;
- deploy em Docker/VPS/Cloudflare sem dependência de PaaS específico;
- sem inventar dados: preços, horários, moradas, avaliações e links sociais
  apenas quando confirmados.

## Decisão

### 1. Static-first com Next.js (`output: "export"`)

Toda a aplicação é exportada para HTML/CSS/JS estático em `out/` e servida por
Nginx em container Docker. Não existe runtime Node.js em produção.

- `trailingSlash: true` para URLs canónicas com barra final.
- `images.unoptimized: true`: com export estático não há servidor de
  otimização de imagens; os assets são pré-otimizados (AVIF/WebP + `srcset`) na
  pipeline de assets.
- `poweredByHeader: false` por higiene de segurança.

### 2. 7 locales com rotas próprias, sem fallback silencioso

Registo único em `core/config/locales.ts`:

| Idioma | Código | Rota |
|--------|--------|------|
| Português (PT) | `pt-PT` | `/` (raiz, default) |
| English | `en-US` | `/en/` |
| Español | `es-ES` | `/es/` |
| Français | `fr-FR` | `/fr/` |
| Deutsch | `de-DE` | `/de/` |
| Italiano | `it-IT` | `/it/` |
| Português (BR) | `pt-BR` | `/pt-br/` |

- Cada locale tem conteúdo completo com as mesmas chaves — garantido por tipo
  (`domains/landing/i18n/types.ts` + mapa por código). Nenhum fallback
  silencioso mistura idiomas; locale inexistente resolve em 404.
- Conteúdo por idioma em `locales/{pt-PT,pt-BR,en-US,es-ES,fr-FR,de-DE,it-IT}/common.json`,
  sob o namespace `landing.*` (issue #32), consumido via `domains/landing/i18n`.

### 3. SEO internacional

- `shared/lib/seo.ts` centraliza `absoluteUrl`, `languageAlternates`
  (`hreflang` recíproco para todos os locales + `x-default` para `/`) e
  `buildLocaleMetadata` (canonical autorreferencial, Open Graph, robots).
- `app/sitemap.ts` e `app/robots.ts` geram os artefatos estáticos.
- `site.indexable` é controlado por `NEXT_PUBLIC_SITE_INDEXABLE`; até ao
  lançamento oficial as páginas saem com `noindex` (não indexar conteúdo
  provisório com URL local).
- JSON-LD (`buildOrganizationJsonLd`) restrito a `EducationalOrganization` com
  dados confirmados; proibido `Review`/`AggregateRating`/preços/horários até
  confirmação.

### 4. Temas light/dark

- `next-themes` + `shared/components/theme/*` com `color-scheme`, persistência
  e supressão de flash no head (`document-shell`).
- Guard de montagem hidratação-safe em `ThemeToggle` via `useSyncExternalStore`
  (cliente = `true`, servidor = `false`) em vez de `setState` em efeito.
- Contraste AA e `prefers-reduced-motion` validados no QA mobile-first.

### 5. WhatsApp contextual

- `shared/lib/whatsapp.ts` + `shared/components/whatsapp-link.tsx` geram o link
  `https://wa.me/351214744028` com mensagem pré-preenchida por secção
  (`hero`, `individual`, `group`, `best_kids`, `footer`, …).
- Número e telefone confirmados (`site.ts`): `+351 21 474 4028` / WhatsApp
  `351214744028`.
- Conversões futuras vão para `dataLayer` tipado (`shared/lib/analytics.ts`),
  sem acoplar fornecedor; fase 1 usa Cloudflare Web Analytics (sem cookies).

### 6. Publicação: Docker/VPS/Cloudflare, independente de fornecedor

- Artefato estático (`out/`) servido por Nginx em container Docker; sem
  dependência de PaaS.
- Cloudflare na frente para CDN/cache; token via `NEXT_PUBLIC_CF_WEB_ANALYTICS_TOKEN`
  (vazio = beacon desativado; ver `docs/analytics-kpis.md`).
- URL pública definitiva via `NEXT_PUBLIC_SITE_URL` (domínio pendente de
  confirmação; fallback local `http://localhost:3000` apenas para dev).

### 7. Tooling: ESLint 9.x (pin) para compatibilidade com eslint-config-next 16.3.0

Durante a auditoria, `eslint@10.8.0` quebrava o lint com
`contextOrFilename.getFilename is not a function`: o `eslint-config-next@16.3.0`
declara peer `eslint >=9.0.0`, mas os plugins internos
(`eslint-plugin-import@2.32.0`, `eslint-plugin-jsx-a11y@6.10.2`,
`eslint-plugin-react@7.37.5`) só suportam ESLint até `^9`.

- **Decisão:** pin `eslint@^9.39.5` (última 9.x). Alinhado ao ecossistema Next;
  não é contornável por `eslint.config.mjs` (o erro é interno do plugin) e
  overrides de plugin arriscariam quebrar as regras oficiais do Next.
- Reavaliar quando `eslint-config-next` publicar suporte oficial a ESLint 10.

## Consequências

### Positivas

- Custo de infraestrutura mínimo e deploy simples (estáticos + Nginx).
- Performance previsível e SEO internacional forte (URLs próprias + hreflang).
- Independência de fornecedor de hosting/PaaS.
- Sem runtime Node em produção reduz superfície de segurança.

### Negativas / Trade-offs

- Sem SSR/ISR dinâmico: mudanças de conteúdo exigem novo build (aceitável
  para landing estática).
- Imagens sem otimização runtime: a pipeline de assets é responsável por
  AVIF/WebP e `srcset`.
- Domínio, horários, e-mail, coordenadas e links sociais permanecem pendentes
  de confirmação e não entram no código (regra: não inventar dados).

## Compliance

- Mobile-first: CSS base para smartphone com breakpoints `min-width` em
  48rem, 64rem e 90rem.
- Locales com as mesmas chaves, sem fallback silencioso.
- `lang`, canonical, `hreflang`, `x-default` e sitemap por idioma.
- Temas sem flash, `prefers-reduced-motion` e contraste AA.
